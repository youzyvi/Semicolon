Practice

What we might work on in class.

These are sample activities for a beginner C++ workshop. The exact pace depends on who joins and what people need more help with.

Session 1

Console basics

Print output, collect user input, and make a tiny interactive profile program.

Session 2

Decision makers

Use if statements to build grade checkers, password prompts, and choice-based programs.

Session 3

Loop challenges

Practice repetition with number games, pattern printing, and input validation.

Mini project

Beginner showcase

Build a small C++ program and explain how it works from top to bottom.
